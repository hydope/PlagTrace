How PlagTrace compares

PlagTrace is not trying to beat Turnitin, Scribbr, or GPTZero at their own game — web-wide database size. It wins on the things that protect a student from a wrong, unappealable output, and it loses on database size. Both are stated here.

Where PlagTrace is better (checkable in this repo)

  • Privacy: local check uploads nothing; internet check sends only short search phrases, opt-in.
  • Transparency: every figure has a formula, settings, and visible passages. No verdict, no "risk: High" label, no AI %.
  • Safety workflow: per-match reviewer decisions, an author-response step, excluded passages listed, removed sources named in the report.
  • Cost: free, no account, no per-check price. Code is open and inspectable.
  • Upload options: paste, clipboard, drag & drop, file picker, multi-file corpus — .txt, .md, .docx, .pdf (text layer), code.

Where PlagTrace loses (stated, not hidden)

  • Database: no web, academic, or publisher database. On web-wide recall, Turnitin-style tools win by construction.
  • Paraphrase and translation: heavy rewording and translation are blind spots.
  • Grammar and style: not included. PlagTrace does similarity only.

Open-source tools it builds on

Methods, reimplemented from published descriptions (not copied code): Winnowing (Schleimer et al., SIGMOD 2003), JPlag's token-based code comparison, Dolos's identifier masking, and copydetect's Winnowing + HTML-report idea. Full table with licenses and sources is in the repo's COMPARISON.md.
