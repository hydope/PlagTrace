Check similarity, not guilt.

Paste or upload essays, papers, and academic drafts — even if you have no second document. PlagTrace shows, source by source, exactly which passages match, how many words matched, and what was excluded. The local check never leaves your device.

Scope, stated up front: Without a second document, use the optional internet search below (Wikipedia + scholarly search). It does not search the whole web, Turnitin's database, or any publisher database. A "no match" means "no match in the sources fetched" — never "no match anywhere". See Internet check.

This is a screening aid. Only a human reviewer may decide misconduct, after giving the student a chance to respond.

    3 · No second document? Optional internet sources

    Privacy trade-off, read before clicking: the local check sends nothing anywhere. Clicking below is the only step that sends anything out — the search phrases taken from Document A go to Wikipedia's public API and, best effort, Semantic Scholar. Full documents are never uploaded; only short search phrases are sent, and the comparison itself still runs in your browser.

    Fetched articles are added as reference sources above, with a link to each source. Untick or remove them like any other source. If Wikipedia or Semantic Scholar rate-limits you, that is reported — it is never read as "no match".
