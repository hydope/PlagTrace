Changelog

v0.6.1 — 2026-10-25 (.docx fix only, engine and accuracy numbers unchanged)

  • Fixed .docx upload failing with "Could not find word/document.xml" on real Word/Pages files. Cause: the old extractor scanned local ZIP headers, which break when a writer uses the data-descriptor flag (compressed size left as 0 locally). The extractor now reads the ZIP central directory, which always holds true sizes and offsets, with the old scan only as a fallback. Proven with a data-descriptor .docx that failed before and extracts now, plus a real python-docx file.
  • .docx text is now paragraph-aware: runs inside a paragraph join with no space (so a word split across runs does not become two words), paragraphs join with a blank line.
  • New tests: tests/files.test.mjs (5 tests, run in CI) covering normal, data-descriptor, and missing-document .docx files.
  • If a .docx still cannot be read, the error now says so plainly and gives the workaround (copy-paste, or save as .txt) instead of a cryptic internal path.

v0.6.0 — 2026-10-24 (engine unchanged, so v0.5.0 accuracy numbers still apply)

  • Stale results fixed: editing a document, changing a setting, or removing a source marks results as outdated until you re-run.
  • Removed sources now named on screen (fully removed this session plus unticked for this run), not only in the JSON export.
  • Reviewer decisions kept across re-scans for matches that still exist, with a "decisions kept" note.
  • Limitations page rebuilt with the full header/nav/footer and corrected wording: local check has no web search, optional internet check is Wikipedia + Semantic Scholar only.
  • Step order fixed: Sources (including internet) is now step 2, Check is step 3. Internet search no longer tells you to run an unnecessary second check.
  • Semantic Scholar failures now distinguish a network/browser block from a rate limit (HTTP 429) or other HTTP error.
  • Results panel now defines every metric and band in plain words. Advanced settings show a "Defaults" / "N setting(s) changed" badge.
  • Keyboard: Enter/Space on a dropzone opens its file picker. Print stylesheet: report only, no inputs or hero. Export: zero matches now correctly reports decisions as incomplete ("No matches to review").

v0.5.0 — 2026-10-24 (published 2026-10-24)

  • Accuracy page rewritten after a second critic review (8.5/10): leads with "about 1 in 5 flags was innocent" (first set) and paraphrase 0/3; counts by pair with 95% Wilson intervals; per-category table; held-out 30-pair set (precision 0.83, recall 0.67, FPR 0.13); base-rate illustration (at 2% prevalence, ~91% of flags innocent); Wikipedia result relabelled a smoke test; version/tag stated.
  • Code fix: a single short passage alone no longer flags for review (2 matches, or ≥150 chars, or ≥90 matched chars covering ≥50% of Document A). Unflagged passages are still shown, labelled "not flagged". Cost: main-set recall fell to 0.57 — stated, not hidden.
  • Accuracy page with measured numbers on a 20-pair set: precision 0.82, recall 1.00, false-positive rate 0.18 — including the two false positives, named. (Superseded by the 25-pair + 30-pair held-out numbers above.)
  • Docs converted from raw .md links to proper HTML pages.
  • Hero trimmed to one line + Learn more; disclaimers collapsed into details.
  • One-click sample check: loads the demo pair and runs it.
  • Document B now clearly optional; settings hidden under Advanced with plain-language labels and a Reset button.
  • Author, contact (GitHub issues), and security note added.
