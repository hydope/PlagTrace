Changelog

v0.7.1 — 2026-10-25 (check cited sources by DOI, engine and accuracy numbers unchanged)

  • New button in step 2: "Check my cited sources (by DOI)". For every DOI in your document it fetches that article's abstract via OpenAlex (works endpoint, CORS *) with a DOAJ fallback, adds it as a reference source, and shows a per-DOI status list. A failed fetch is listed as not fetched, never as 0%.
  • Verified on the real paper: 12/12 DOIs fetched, 12/12 abstracts via OpenAlex. Comparison against all 12 cited abstracts is still 0% — because the paper paraphrases its sources, it does not copy their abstracts verbatim, and this engine is verbatim-only (minimum 8 words / 40 chars). Proof the engine would catch a real copy: a test document containing 300 verbatim characters from the Donaldson & Preston abstract scored 80.4% union, 1 passage, 295 chars.
  • Limit stated plainly: abstracts only. Full text is usually behind a publisher paywall or a browser CORS block, so a cited full text that matches a paraphrased sentence in your paper will still not be found by any verbatim tool — that is a paraphrase blind spot, not a 0% bug, and it is why the tool never calls a result "clean".

v0.7.0 — 2026-10-25 (free-database integration, engine and accuracy numbers unchanged)

  • DOAJ integrated: open-access journal abstracts are now searched with your phrases (first 6 words, because a 12-word DOAJ query returns nothing) and compared locally, with a link to each article. Verified on the real paper: 4 DOAJ abstracts added (e.g. "Short-term thinking, long-term costs: How managerial myopia undermines green innovation"); 0-match abstracts collapse to one line under v0.6.4, they do not get empty cards. Pre-publish fix: DOAJ article links now correctly prefer the fulltext URL and fall back to the DOI URL — the first build could have produced a broken doi.org/undefined link for articles without a DOI.
  • Pre-publish fix: the JSON report scope and the results warning now correctly say Wikipedia + DOAJ + OpenAlex + Semantic Scholar, not the old "Wikipedia + Semantic Scholar only" wording.
  • OpenAlex integrated, best effort: inverted-index abstracts are reconstructed locally when the API responds. It returned HTTP 429 on this shared network, so that failure is reported, never read as "no match".
  • Unpaywall DOI lookup (optional): enter a real email in step 2 and PlagTrace lists open-access copies for the DOIs in your References. This finds copies only — it does not compare text, and it never claims to. Example.com addresses are rejected, as Unpaywall requires.
  • Total internet source cap raised from 6 to 12 so the new databases are not crowded out by Wikipedia.
  • NOT integrated, with evidence: Crossref (200, CORS *, but 0/5 items had an abstract — metadata only, nothing to compare); arXiv, Europe PMC, CORE, Open Library (200 in Node, but no CORS header, so a browser cannot fetch them from a static site at all); Wikidata (metadata only, no text). A server proxy would fix CORS but would break the no-upload privacy model, so it is not used.

v0.6.4 — 2026-10-25 (fixes for the 0% academic-paper run, engine and accuracy numbers unchanged)

  • 0-match internet sources no longer get full empty cards: they collapse into one line ("X source(s) fetched and compared locally — no passage met the threshold"), with an explanation that Wikipedia keyword search returns related articles, not exact-phrase matches. Sources with a real match still get full cards.
  • New "Not checked — your cited sources" section: entries parsed from the document's own References section (verified on the real paper: 12 entries), with the plain statement that PlagTrace did not check them because it has no access to journal articles, books, or publisher databases. A 0% above does not cover these — upload a cited article's full text as a reference source to check it.
  • Fixed "Excluded from scoring: None" in corpus mode: it now shows the actual excluded spans (quoted text and the References/Bibliography tail) instead of an empty list.
  • Search phrases no longer start with a citation lead-in: "Widyaningsih et al. (2026) explore digital ESG…" now searches as "explore digital ESG and sustainable firm value among ASEAN companies including factors" (verified on the real paper). The previous phrase started with "2026".
  • Evidence for why the old run looked like a joke, measured, not guessed: unquoted Wikipedia search for the paper's three phrases returned Stakeholder theory / Srettha Thavisin / Capital Markets Union / Fair trade / Sweatshop / Occupational safety and health — keyword hits, not phrase matches — while Semantic Scholar returned HTTP 429 on this network and "Load failed" in the user's browser. The comparison itself was correct (0% against Wikipedia); the presentation hid the real gap, which was the 12 unchecked journal articles.

v0.6.3 — 2026-10-25 (competitor-inspired features, engine and accuracy numbers unchanged)

  • Results summary bar, inspired by GPTZero's top line but with scope attached: coverage donut (not a verdict), words matched, sources checked, sources flagged, passages total, plus a checklist (Document B, sources checked, exclusions, reviewer decisions pending, and "AI %: deliberately not shown").
  • Per-source cards v2, inspired by GPTZero/Scribbr cards: numbered [1], [2], source link, words matched first, coverage, band, flagged/context, and a matched passage shown with surrounding context highlighted, plus a prominent Copy citation button.
  • Sticky action bar (Re-scan, JSON, CSV, Print) so the actions stay reachable on long results, like GPTZero's Re-scan button.
  • CSV export of per-source results (source, URL, included, coverage, words, passages, longest, band, flagged) for reviewers who live in spreadsheets.
  • Dark mode with a persistent preference, and a 10 MB per-file limit with a clear error instead of a freeze.
  • Deliberately NOT copied from these screenshots: AI % (T-Checker 86% vs Scribbr 78% on the same paper proves it is inconsistent), "Go to Humanizer" (evasion), "No plagiarism found" (Grammarly scanned only the first 1,500 words), "Plagiarism risk: High" (Scribbr hides its % behind a blur and a $19.95 paywall), and grammar checking (a different product; a fake grammar count would be dishonest).

v0.6.2 — 2026-10-25 (internet search fix + safety warning, engine and accuracy numbers unchanged)

  • Fixed internet search phrases for academic papers. Old scoring picked headings, title pages, and generic filler ("Recommendations for Business Leaders…", author/university lines) because it scored by long words and merged headings with the next paragraph. New scoring: references section cut, headings/title lines dropped, sentences scored by distinctive words (words appearing in few other sentences) with a bonus for cited sentences. On a real stakeholder-theory paper, phrases changed from title/generic filler to a Donaldson & Preston (1995) stakeholder sentence and a digital-ESG ASEAN sentence — and Wikipedia now returns the actual "Stakeholder theory" article first, instead of six unrelated articles.
  • Added an unmissable warning on internet/corpus results, and before the search button: a 0% here does NOT mean a paper is clean. This check covers Wikipedia and Semantic Scholar abstracts only — it does not check journal articles, books, publisher databases, or other students' work, which is what university checkers use. Never treat it as a Turnitin result.
  • Honest limit, still true: even with better phrases, a paper can score 0% here and still match a cited journal article, because those journals are not in Wikipedia. That limit is now stated on the results page, not just in a disclaimer.

v0.6.1 — 2026-10-25 (.docx fix only, engine and accuracy numbers unchanged)

  • Fixed .docx upload failing with "Could not find word/document.xml" on real Word/Pages files. Cause: the old extractor scanned local ZIP headers, which break when a writer uses the data-descriptor flag (compressed size left as 0 locally). The extractor now reads the ZIP central directory, which always holds true sizes and offsets, with the old scan only as a fallback. Proven with a data-descriptor .docx that failed before and extracts now, plus a real python-docx file.
  • .docx text is now paragraph-aware: runs inside a paragraph join with no space (so a word split across runs does not become two words), paragraphs join with a blank line.
  • New tests: tests/files.test.mjs (5 tests, run in CI) covering normal, data-descriptor, and missing-document .docx files.
  • If a .docx still cannot be read, the error now says so plainly and gives the workaround (copy-paste, or save as .txt) instead of a cryptic internal path.

v0.6.0 — 2026-10-24 (engine unchanged, so v0.5.0 accuracy numbers still apply)

  • Stale results fixed: editing a document, changing a setting, or removing a source marks results as outdated until you re-run.
  • Removed sources now named on screen (fully removed this session plus unticked for this run), not only in the JSON export.
  • Reviewer decisions kept across re-scans for matches that still exist, with a "decisions kept" note.
  • Limitations page rebuilt with the full header/nav/footer and corrected wording: local check has no web search, optional internet check is Wikipedia + Semantic Scholar only.
  • Step order fixed: Sources (including internet) is now step 2, Check is step 3. Internet search no longer tells you to run an unnecessary second check.
  • Semantic Scholar failures now distinguish a network/browser block from a rate limit (HTTP 429) or other HTTP error.
  • Results panel now defines every metric and band in plain words. Advanced settings show a "Defaults" / "N setting(s) changed" badge.
  • Keyboard: Enter/Space on a dropzone opens its file picker. Print stylesheet: report only, no inputs or hero. Export: zero matches now correctly reports decisions as incomplete ("No matches to review").

v0.5.0 — 2026-10-24 (published 2026-10-24)

  • Accuracy page rewritten after a second critic review (8.5/10): leads with "about 1 in 5 flags was innocent" (first set) and paraphrase 0/3; counts by pair with 95% Wilson intervals; per-category table; held-out 30-pair set (precision 0.83, recall 0.67, FPR 0.13); base-rate illustration (at 2% prevalence, ~91% of flags innocent); Wikipedia result relabelled a smoke test; version/tag stated.
  • Code fix: a single short passage alone no longer flags for review (2 matches, or ≥150 chars, or ≥90 matched chars covering ≥50% of Document A). Unflagged passages are still shown, labelled "not flagged". Cost: main-set recall fell to 0.57 — stated, not hidden.
  • Accuracy page with measured numbers on a 20-pair set: precision 0.82, recall 1.00, false-positive rate 0.18 — including the two false positives, named. (Superseded by the 25-pair + 30-pair held-out numbers above.)
  • Docs converted from raw .md links to proper HTML pages.
  • Hero trimmed to one line + Learn more; disclaimers collapsed into details.
  • One-click sample check: loads the demo pair and runs it.
  • Document B now clearly optional; settings hidden under Advanced with plain-language labels and a Reset button.
  • Author, contact (GitHub issues), and security note added.
