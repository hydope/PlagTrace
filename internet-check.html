Internet check

If you have no second document, PlagTrace can search the internet for you — with limits you should know before you rely on it.

How it works

  1. Paste your text, click Search internet sources.
  2. PlagTrace takes up to 3 distinctive sentences, truncates each to 12 words, and sends only those phrases to Wikipedia's public API and, best effort, Semantic Scholar.
  3. Up to 6 Wikipedia articles are fetched and compared locally, in your browser, with a link to each source.
  4. The exact phrases sent are shown on screen. Full documents are never uploaded.

What it does not search

Not the whole web. Not Turnitin's database. Not publisher paywalled databases. Not Chegg or CourseHero — those are paywalled, and no free open tool can search them. If a match lives only there, PlagTrace will not find it.

Have a specific page in mind? If you can open a page (a blog, a CourseHero page you have access to, a classmate's paper), copy its text and paste it as Document B or as a reference source. That is how you check a specific source PlagTrace cannot fetch itself.

Rate limits, reported not hidden

Semantic Scholar returned HTTP 429 from a shared network in testing (no API key), OpenAlex did the same, and arXiv returned HTTP 503. Those failures are shown in the tool — they are never read as "no match". Wikipedia worked with no key in the same test.

What "no match" means here

"No match in the Wikipedia articles fetched" — never "no match anywhere".
